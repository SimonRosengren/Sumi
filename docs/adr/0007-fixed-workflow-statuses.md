# 7. Fixed workflow statuses in v1

- Status: accepted
- Date: 2026-10-29

## Context

Custom workflows add a lot of complexity and are not needed yet.

## Decision

Statuses are fixed: backlog, todo, in_progress, in_review, done. One board per project.

## Consequences

Simple model and simple UI. Teams cannot customise columns until a new ADR changes this.
